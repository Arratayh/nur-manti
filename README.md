# Nur Mantı — Web Sitesi

Pendik’teki **Nur Mantı** için hazırlanmış, 1800’ler Osmanlı salonu estetiğinde tek sayfalık tanıtım sitesi.

## Çalıştırma

Tarayıcıda `index.html` dosyasını açın veya yerel sunucu:

```bash
python -m http.server 5173
```

Ardından: http://localhost:5173

## İçerik

- Gerçek mekân / yemek fotoğrafları (Yandex Maps galerisi)
- Google misafir yorumlarından alıntılar
- Adres, telefon, çalışma saatleri, harita
- Menü: yoğurtlu mantı, çıtır mantı, çiğ börek, içli köfte & ev baklavası

## Dosyalar

- `index.html` — sayfa
- `css/styles.css` — stil
- `js/main.js` — navigasyon & scroll animasyonları
- `assets/images/` — görseller
